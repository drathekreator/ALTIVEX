# 🚀 PROJECT BRIEF: ALTIVEX (Altitude & Vital Monitoring System)

## 📌 Deskripsi Proyek
**ALTIVEX** adalah sistem pemantauan geospasial dan fisiologis dua arah (*bidirectional*) berbasis *Internet of Things* (IoT) yang dirancang khusus untuk mitigasi kecelakaan pendaki gunung di area nirsinyal (*blank spot*). Sistem ini mengawinkan komunikasi radio frekuensi mandiri (LoRa P2P) dengan arsitektur *local server* berkinerja tinggi berbasis Rust dan *dashboard* pemantauan *real-time*.

---

## 🏗️ Arsitektur Sistem & Alur Data (Data Flow)
Sistem beroperasi dengan topologi *offline-first* (tanpa ketergantungan internet publik selama di gunung):
1. **Uplink (Pemantauan):** Sensor Fisik & GPS Pendaki ➡️ Heltec Transmitter ➡️ Gelombang LoRa P2P ➡️ Heltec Receiver Basecamp ➡️ Kabel USB (Serial CDC) ➡️ Local Server Rust ➡️ PostgreSQL DB ➡️ Web Dashboard (AJAX Polling).
2. **Downlink (Sinyal Umpan Balik/Getar):** Petugas Pos Jaga klik tombol di Web Dashboard ➡️ REST API (`POST /api/alert`) ➡️ Server Rust menulis ke Serial Port (`/dev/ttyUSB0`) ➡️ Heltec Basecamp memancarkan JSON perintah ➡️ Gelombang LoRa ➡️ Heltec Pendaki memicu aktuator Motor Vibrator.

---

## 🛠️ Tumpukan Teknologi (Tech Stack)

### 1. Perangkat Keras (Hardware)
* **Mikrokontroler Utama:** Heltec WiFi LoRa 32 V3 (ESP32-S3 + SX1262 LoRa Chip).
* **Modul Navigasi:** GPS Ublox NEO-6M (UART) & Magnetometer QMC5883L (I²C).
* **Sensor Biometrik:** MAX30102 untuk mengukur SpO₂ dan *Heart Rate* (I²C).
* **Aktuator Peringatan:** Motor Vibrator dengan sirkuit *switch* Transistor NPN (BC547/2N2222) + Dioda *Freewheeling* 1N4007 dihubungkan ke GPIO 21.
* **Catu Daya:** Baterai Li-Po melalui modul *charger* TP4056 menuju pin VBAT.

### 2. Lingkungan Server Lokal (Basecamp)
* **OS & Container:** Ubuntu Server / WSL 2 di Windows (terhubung via `usbipd-win` untuk *forwarding port* USB kelistrikan fisik).
* **Database:** PostgreSQL (versi 15-alpine) berjalan di dalam Docker Container (`docker-compose.yml`) dengan persistensi data menggunakan *volume*.
* **Backend API:** Ditulis dalam bahasa **Rust** menggunakan *framework* **Actix-web** (v4), *runtime* **Tokio**, ORM **SQLx** (koneksi asinkron ke Postgres), dan pustaka **serialport** (v4.3) untuk komunikasi *serial/UART* ke *board* penerima.

### 3. Antarmuka Pengguna (Frontend Dashboard)
* **Konsep UI/UX:** *Single Page Application* (SPA) dengan tata letak responsif (*Flexbox/Grid*), menggunakan palet warna pastel (*Soft Cream* `#fdfbfb`, *Soft Green* `#d8e2dc`, *Soft Pink* `#ffcad4`) bergaya **Kartu Pendaki Modern (*Hiker Cards*)**.
* **Teknologi:** HTML5, CSS3 murni, dan Vanilla JavaScript (Tanpa *framework* berat).
* **Pemetaan Spasial:** **Leaflet.js** terintegrasi dengan ubin peta (*map tiles*) OpenStreetMap (mendukung *caching/offline mapping*).
* **Fitur Dasbor:**
    * *Real-time update* posisi *marker* dan data biometrik via AJAX Polling tiap 3 detik.
    * **Geofencing:** Menggambar zona aman (lingkaran hijau radius 500m).
    * **Deteksi Kritis:** Mengubah kartu UI menjadi merah dan memunculkan tombol aksi jika pendaki keluar dari *Geofence* atau mengalami indikasi hipoksia (SpO₂ < 90%).

## 🔌 Pemetaan Pin (Pin Mapping) - Node Pendaki

| Komponen | Pin Komponen | Pin Heltec V3 (ESP32-S3) | Protokol | Keterangan |
| :--- | :--- | :--- | :--- | :--- |
| **MAX30102** | SDA / SCL | GPIO 17 / GPIO 18 | I²C | Berbagi *bus* I²C (Alamat `0x57`) |
| **QMC5883L** | SDA / SCL | GPIO 17 / GPIO 18 | I²C | Berbagi *bus* I²C (Alamat `0x0D`) |
| **GPS NEO-6M**| TX / RX | GPIO 45 / GPIO 46 | UART | Jalur UART1 ESP32-S3 |
| **Vibrator** | Positif (+) | GPIO 21 | Digital Out| Menggunakan sirkuit Transistor NPN |

*(Node Basecamp tidak menggunakan sensor eksternal, murni bertindak sebagai LoRa-to-USB Serial Bridge).*
